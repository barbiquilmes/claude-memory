### Learnings
- Before building a skill in a loop of attempts, ask for real input files. Sessions without real inputs produced inconsistent test results.
- Load deferred tool schemas via ToolSearch before first use of `Skill`, `Edit` or `Write`, to avoid avoidable tool errors.
- Run the template's `validate.py` on every new skill; it catches absolute paths in SKILL.md.
- Never overwrite an existing skill directory with a different template. Create a new one when the user names a different skill.
- When the user names a project skill ("create python skill"), use it (`create-python-skill`) instead of falling back to a global plugin like `skill-creator`.
