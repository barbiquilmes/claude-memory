### Learnings
- In a Lambda-backed passkey login, the `login/start` request sits on the critical path before the OS passkey sheet appears. Lambda cold starts therefore show up directly as UI latency.
- Lambda CPU scales with memory. A default 128 MB function with FastAPI, boto3 and a webauthn library paid about 2.7 s of init time per cold start.
- `LastModified` on the Lambda compared with the commit timestamps on `main.py` is a workable way to infer the deployed version when there are no tags. It is an inference, not a hash match.
- Before switching branches, `git stash push -u` handles both modified and untracked files.
